# Research brief — three Hidook systems

You are doing visual research, not shipping a new product identity from vibes.

## For each of 5 sites

Capture:

- desktop ~1440
- mobile ~390
- note Instagram / social presence (feed, link, embed, or none)

Record:

- hero / first screen job
- primary action (book, menu, call, estimate)
- type + color + imagery
- how work/menu/projects are shown
- how Instagram is treated (or missing)
- adapt / avoid

## What to steal (adapt)

Restaurants: photography as the product, menu reachable in one tap, tight type, reservation CTA, Instagram as living proof not a footer afterthought.

Beauty: book-now always visible, real work photos first, calm luxury not beige sludge, Instagram/grid of real clients.

Construction: phone / estimate above the fold, project photography that builds trust, services as proof not icon tiles, Instagram as job-site proof.

## What to avoid

- Generic SaaS card grids and indigo gradients
- Stock-photo heroes
- Hidden menus / PDFs as the only menu
- Cloning Apple.com chrome or any one brand 1:1
- Instagram as a tiny footer glyph with no feed

## Output the synthesizer needs

One `04-synthesis/<vertical>-patterns.md` with:

- 5-row adapt/avoid table
- winning composition for our template
- Instagram module spec (embedUrl iframe + fallback gallery)
- tokens (bg, ink, accent, type, radius) derived from the set, not from one clone
