# Suite C — portfolio gallery carousel screenshots

PLAN-FEEDBACK-2026-09-13.md, Suite C (punct 3). PNGs are gitignored (QA
evidence screenshots are regenerated by the oracles on every run); this
README documents what each one showed at capture time so the evidence
survives even though the images themselves are not committed.

All four screenshots are of `.collage-stage` (one category) built with a
synthetic category of the stated photo count, using the demo photos already
shipped in `templates/portfolio/images/` (cycled to reach the count), via
`build.js`'s real `build()` — the same renderer a live publish uses.

- `gallery-5photos-390w.png` — 5 photos, 390px viewport (mobile). 2 uniform
  tiles visible, both prev/next `<button>`s shown (carousel engaged — 5
  photos don't fit 2-per-row), no page horizontal scroll.
- `gallery-5photos-1280w.png` — 5 photos, 1280px viewport (desktop). 3
  uniform tiles visible, prev disabled (already at the first photo), next
  enabled (2 more photos to scroll to). No orphan photo stretched to fill
  the partial last row — the WAVE10 defect this Suite fixes.
- `gallery-9photos-390w.png` — 9 photos, 390px. Same 2-tile layout as the
  5-photo case (tile size is independent of count) — carousel engaged.
- `gallery-9photos-1280w.png` — 9 photos, 1280px. Same 3-tile layout as the
  5-photo case — carousel engaged, more photos to reach via next.
